# 29 Ekim — kurgu v1

Kaynak: Drive "cem abi 29 Ekim" (23 WhatsApp videosu, 3 drone, 1 MP3).

## Resolve'a alma
1. Drive klasörünü bilgisayara indir (alt klasörler `dron/` ve `mp3/` aynı kalsın).
2. Resolve: File → Import → Timeline → `29Ekim_KURGU_v1.fcpxml` (ve istersen `29Ekim_SENKRON.fcpxml`).
   Proje ayarı 1920x1080, 30 fps.
3. Klipler offline gelirse Media Pool'da hepsini seç → sağ tık → Relink Selected Clips → indirdiğin klasörü seç.
